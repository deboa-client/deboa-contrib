<h1><b>Deboa Contrib</b></h1>
</div>

**Deboa Contrib** is a collection of extension crates for Deboa. It offers a rich array of modern features like SSE and multiple serialization formats.

Built on top of [deboa](https://github.com/ararog/deboa).

## Features

Please refer to the individual crate documentation for details:

- [deboa-extras](./deboa-extras#features)
- [deboa-fory](./deboa-fory#features)
- [deboa-hickory](./deboa-hickory#features)
