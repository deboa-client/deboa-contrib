## Deboa Fory

Hickory Resolver support for Deboa

## Features

All futures provided by hickory-resolver can be enabled.

## Install

Either run from command line:

`cargo add deboa-hickory`

Or add to your `Cargo.toml`:

```toml
deboa-hickory = "0.0.1"
```
